Render Free deploy fix + LOGIN FIX
======================
This change fixes the startup crash caused by trying to create /var/data/stratic-market/images when no Persistent Disk is mounted.

On Render Free, the store now uses /tmp/stratic-market unless DATA_DIR is explicitly set. This is only a startup workaround. /tmp is ephemeral; products, accounts, orders, stats, and uploaded images may disappear after restart/redeploy. DATABASE_URL/Neon is not automatically used by this JSON file store. Do not treat this build as production-ready for persistent customer data until the shop-store is migrated to PostgreSQL and image uploads use persistent object storage.

No visual/UI files were intentionally changed.

LOGIN FIX (session persistence)
-------------------------------
1. Accounts are now backed up to Postgres (Neon, via DATABASE_URL) table sgm_kv and restored on every start.
   Needs DATABASE_URL set in Render Environment. (package.json now includes "pg".)
2. If SESSION_SECRET is missing, a stable secret is derived (cookies no longer die on restart). Best: set SESSION_SECRET (32+ chars).
3. shop.js: the Google "needphone" / error result was lost because the URL was cleaned before it was read. Fixed.
Products/orders/images are still on /tmp (unchanged).

ROUND 2
-------
- New Google users are now created and logged in instantly (no hidden phone step).
- /static js/css no longer cached 1h (old shop.js stayed in browser after redeploy).
- Client re-checks /me after Google redirect; registration-only fields no longer show on Sign in.

LAUNCH BUILD (v3)
-----------------
- Accounts, products, orders, stats AND product photos are mirrored to Neon (DATABASE_URL) and restored on start.
- Dialogs (Cart/Profile/Checkout/Sell) are centered; desktop layout is wide with a centered bottom bar.

- Buy Now / Checkout = real order; full green "Order confirmed" screen; one order per seller.
- Same mobile number cannot sell and buy (one number = one account, checked for buyer + seller phone).
- Sell: one photo -> 5 photos (studio, tilted, close-up, reflection, warm backdrop), tap card image for gallery.
