30,000 कंपनियों को क्या देना है?

  1. नीचे कंपनी का नाम डालो → Create दबाओ
  2. दो लिंक बनेंगे:
    • Tool link — कंपनी के staff / CEO के लिए (console)
    • Customer link — कंपनी अपने ऐप के Help बटन पर लगाए
  3. ये दोनों लिंक सिर्फ उसी कंपनी को भेजो (WhatsApp / email)
  4. दूसरी कंपनी = नया Create → नए दो लिंक (मिलेंगे नहीं एक-दूसरे से)

एक कंपनी का refund / data दूसरी कंपनी के Tool पर नहीं जाएगा।
उसी नाम से Create = वही लिंक (Microsoft → हमेशा same)। Data टिके: Render Disk + AAPKA_DATA=/var/data।

अभी बने लिंक — कंपनी को ये दो भेजो

1. Tool link (staff / CEO)
2. Customer link (Help button)

सभी कंपनियाँ

Tool के अंदर 6 dashboards

  1. Overview — आज के cases / automation summary
  2. Employee / Agent — inbox, reply, suggested actions
  3. CEO / ROI — hours saved, cases, cost view
  4. Integrations — Salesforce / Zendesk / Payment boxes (कंपनी खुद keys डाले)
  5. History & Audit — उसी कंपनी के refunds / orders (दूसरी कंपनी नहीं दिखेगी)
  6. Customer portal — अलग Customer link से खुलता है

Refund / CRM connect तभी live होगा जब कंपनी Integrations में अपनी keys डाले और Test Connection करे। बिना keys के local demo चलता है।
