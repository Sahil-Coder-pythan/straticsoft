# Stratic Global Market (Milestone 1)
Run locally: `pip install -r requirements.txt && python app.py`
Render: Build `pip install -r requirements.txt`, Start `gunicorn app:app`.
Env vars: SECRET_KEY (random long string), DATABASE_URL (Render PostgreSQL Internal URL).
## Done: homepage, market selector, search/filter/sort, register/login, seller dashboard, products, cart, COD orders, seller accept/reject/deliver, cancel, server-side country checks, CSRF.
## Not done: payments, admin panel, photo upload, reviews, policies, seller verification, rate limiting.
