# StratisSoft Master Suite
Render **Web Service** (Node). Build: `npm install`  Start: `npm start`

Environment variables: GOOGLE_CLIENT_ID, BREVO_API_KEY, MAIL_FROM (verified sender in Brevo).
Google Cloud: add your Render URL to Authorized JavaScript origins.
Tools live in `public/tools.js` (one F(...) block per tool). External tool SSO: see SSO_SNIPPET_for_external_tools.md
