## Render.com पर Live करने का तरीका और Environment Section

1. इस फोल्डर को अपने GitHub Repository में Push करो।
2. **Render.com** पर जाओ -> **New +** -> **Static Site** चुनो।
3. अपनी Repo सेलेक्ट करो।
4. **Build Command**: खाली छोड़ दो (Blank / Leave empty)
5. **Publish Directory**: `.` (यानी सिर्फ एक डॉट)
6. **Environment Section**: **पूरी तरह खाली छोड़ दो (Nothing needed / No Environment variables needed!)**
   - क्योंकि यह पूरी तरह क्लाइंट-साइड HTML/JS/CSS ऐप्लिकेशन है, इसलिए Render के Environment variables में कुछ भी डालने की ज़रूरत नहीं है!
7. **Create Static Site** पर क्लिक करो। 1 मिनट में लिंक लाइव मिल जाएगा!
