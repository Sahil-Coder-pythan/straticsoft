## Render पर Live Link बनाने का तरीका

1. यह पूरा फोल्डर GitHub पर Public repo में डालो
2. Render.com → New → Static Site
3. Repo select करो
4. Publish Directory = `.`
5. Create Static Site

Link मिल जाएगा: `https://your-name.onrender.com`
